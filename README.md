# ksartis — сайт-визитка

Сайт инженера-конструктора литейного производства. Локальная версия с админкой.

## Запуск

Самый простой способ — двойной клик по **`start.bat`**: откроется браузер и сервер.

Или из терминала:

```powershell
cd G:\opencode\2026-11-25-001\site
node server/server.js
```

> `npm run dev` тоже работает, но если PowerShell блокирует скрипты — используйте `node server/server.js`.

Откроется:

- сайт — http://localhost:8080
- админка — http://localhost:8080/admin

Пароль администратора хранится в `.env` (по умолчанию `ksartis2026` — **смените**).

## 3D-модель на главной

В hero — вращаемая модель `/models/otvod.glb` (отливка «Отвод 180» с литниковой системой).

- мышь — вращение, колесо — зум, двойной клик — сброс;
- на телефоне — палец, пинч для зума;
- если WebGL недоступен — показывается обычное фото.

Заменить модель:

1. Положить готовый `.glb` в `public\models\`.
2. В `public\index.html` у блока `#viewer` поменять `data-model="/models/имя.glb"`.

Конвертировать STL в GLB (без сторонних программ):

```powershell
node tools\stl2glb.js "путь\модель.stl" "public\models\новая.glb"
```

## Как менять работы

1. Откройте `/admin`, введите пароль.
2. Вкладка **«Работы»**:
   - «+ Добавить работу» — новая карточка;
   - «Заменить фото» — выбрать JPG/PNG/WEBP до 20 МБ;
   - название, категория, описание, порядок (меньше — выше);
   - галочка «Опубликовано» — показывать на сайте;
   - «Удалить» — убрать карточку.
3. Нажмите **«Сохранить»**.

Изменения сразу видны на сайте (обновите страницу).

## Настройки

Вкладка **«Настройки»** — бренд, заголовок первого экрана, текст «Обо мне», контакты (Telegram, e-mail, WhatsApp), четыре цифры.

## Смена пароля

Откройте `.env` и измените строку:

```
ADMIN_PASSWORD=ваш-новый-пароль
```

Затем перезапустите сервер (Ctrl+C в окне терминала и снова `npm run dev`).

Заодно поменяйте `SESSION_SECRET` на любую длинную случайную строку.

## Открыть с телефона (та же Wi-Fi)

1. Узнайте IP компьютера: `ipconfig` → «IPv4-адрес».
2. На телефоне: `http://192.168.x.x:8080`.
3. Если не открывается — разрешите Node.js в брандмауэре Windows для частной сети.

## Структура

```
site\
├─ public\            сайт (HTML/CSS/JS, картинки)
│  ├─ index.html
│  ├─ admin.html
│  ├─ style.css
│  ├─ admin.css
│  ├─ app.js
│  ├─ admin.js
│  └─ img\
├─ content\
│  ├─ works.json      работы (название, описание, фото, порядок)
│  └─ settings.json   тексты и контакты
├─ server\
│  └─ server.js       локальный сервер + API (без зависимостей)
├─ tools\
│  └─ make-images.ps1 подготовка фото из архива
└─ .env               пароль и порт (не публиковать)
```

## Резервная копия

Достаточно скопировать папки `content` и `public\img` — там весь контент.
